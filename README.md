# ClimaRuta

ClimaRuta is a modeling and simulation project that aims to show forecast weather conditions during a trip between cities or countries.

Users will enter their origin, destination, departure date, and time.

The following APIs will be used:

- **Open-Meteo Geocoding API:** to locate cities and obtain their coordinates.
- **openrouteservice:** to calculate the route and estimated travel times.
- **Open-Meteo Forecast API:** to retrieve temperature, precipitation, and wind forecasts along the route.

The simulation will compare different departure times to identify when travelers would encounter less rain during the trip.

ClimaRuta es un proyecto de modelado y simulación que busca mostrar las condiciones meteorológicas previstas durante un viaje entre ciudades o países.
El usuario ingresará su origen, destino, fecha y hora de salida.
Se utilizarán las siguientes APIs:
- Open-Meteo Geocoding API: para localizar las ciudades y obtener sus coordenadas.
- openrouteservice: para calcular la ruta y los tiempos estimados del viaje.
- Open-Meteo Forecast API: para consultar la temperatura, las precipitaciones y el viento previstos durante el recorrido.
- 
La simulación permitirá comparar diferentes horarios de salida para identificar cuándo se encontraría menos lluvia durante el viaje.
